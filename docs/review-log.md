# Журнал перевірок і виправлень (ЛР1)

Для кожної перевірки вказано: хто перевіряв, який артефакт, тип перевірки, як саме, результат. Якщо знайдено
проблеми — що виправлено, ким, як і де доказ. **Тип:** «самоперевірка» — автор перевіряє власний артефакт;
«перехресна» — перевіряє інший учасник.
