# Mini Issue Tracker

Навчальний проєкт з дисципліни «Штучний інтелект у програмній інженерії» (ХНУРЕ, 2026–2027 н. р.).
Невеликий локальний REST-сервіс для обліку проблем програмного продукту: заявки, статуси, пріоритети,
виконавці та коментарі. Один репозиторій використовується для всіх чотирьох лабораторних робіт.

**Бригада ПЗПІ-23-6:** Ус Владислав, Козир Дмитро, Мамішев Ельмір, Дроздов Антон.

## Технології (план для ЛР2–ЛР4)

Python 3.12+, FastAPI, SQLite, pytest. Запуск — лише локальний, із синтетичними даними.
Автентифікації немає: два тестові користувачі (Agent A, Agent B) — це довідник, а не система ідентифікації.

## Використання AI

Частину артефактів підготовлено з AI-асистентом (Claude, Anthropic). Кожну взаємодію, прийняті й
відхилені пропозиції та спосіб перевірки зафіксовано в [docs/ai-log.md](docs/ai-log.md).
